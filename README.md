# ForgeLedger

A responsive product site for a blockchain-based, tamper-proof multi-3D-printer management system. The content is based on the supplied implementation design, translated into a polished product narrative.

## Highlights

- Greptile-inspired editorial layout, typography, color system, and section rhythm
- Original ForgeLedger identity and custom CSS network/proof visuals
- Real project content: Solidity access control, IPFS payload storage, AES-256 encryption, printer-fleet orchestration, snapshot commitments, and geometry verification
- Responsive desktop and mobile navigation
- Accessible semantic structure and reduced-motion support
- Statically rendered with Next.js

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
npm audit --omit=dev
```
